# videodl — yt-dlp Video & Subtitle Manager

## 1. Overview

A download management tool built on [yt-dlp](https://github.com/yt-dlp/yt-dlp) for organizing videos
and subtitles. The goal is a well-structured directory layout that works seamlessly with media
players (Infuse, Plex, IINA, etc.) and a static HTML index for browsing via Chrome.

## 2. Requirements

1. Download root directory configurable via `config/.env`
2. Download video + subtitles, English first, with fallback to other languages
3. Directory structure designed for daily management and playback
4. HTTP proxy support (`HTTP_PROXY` / `HTTPS_PROXY`)
5. Static HTML index with native HTML5 video player
6. Built-in HTTP server for Chrome compatibility (file:// blocked by Chrome)

## 3. Architecture & Design

### 3.1 Tech Stack

| Component            | Technology           | Notes                                                             |
| -------------------- | -------------------- | ----------------------------------------------------------------- |
| Download engine      | yt-dlp               | CLI tool, user-managed. No Python libs or scripts in this project |
| Audio/Video merge    | ffmpeg               | yt-dlp dependency, installed by user                              |
| HTML index generator | TypeScript + Node.js | `scripts/gen-index.ts`, via pnpm/tsx                              |
| Player UI            | native HTML5 video   | `<video>` + `<track>` elements                                    |
| HTTP server          | Rust + tiny_http     | `src/bin/static-server.rs`, shared across modules                 |
| Task runner          | just                 | Module recipes via `just videodl::<task>`                         |

### 3.2 Dependency Relationship

```
just videodl::serve
  └─ recipe dep: _build-static-server  (cargo build --bin static-server)
       └─ src/bin/static-server.rs  ← depends on tiny_http (root Cargo.toml)

just videodl::gen-index
  └─ scripts/gen-index.ts — scans VIDEO_DL_ROOT, generates HTML
```

`just videodl::build` builds everything; `just videodl::serve` auto-builds first via just's recipe
dependency mechanism.

### 3.3 Project Structure

```
├── Cargo.toml                        # [dependencies] includes tiny_http
├── src/bin/static-server.rs          # Shared static HTTP server (generic, reusable)
├── modules/videodl/
│   ├── justfile                      # Module recipes
│   ├── README.md                     # Module docs

│   ├── tsconfig.json                 # TypeScript config
│   └── scripts/
│       ├── dl.sh                     # yt-dlp wrapper (classification, naming, retry)
│       └── gen-index.ts              # Directory scanner → index.html + player.html
├── config/.env.example               # VIDEO_DL_ROOT, SUBTITLE_LANGS, HTTP_PROXY
└── .gitignore                        # node_modules/,.cookies
```

## 4. Module Design

### 4.1 Environment Variables (`config/.env`)

```bash
# ── videodl ──────────────────────────────────────
VIDEO_DL_ROOT=/Volumes/Media/yt-dlp           # Download root
SUBTITLE_LANGS="en,zh-Hans,ja,ko"             # Subtitle priority
# VIDEO_DL_EXTRA_ARGS=--limit-rate 5M          # Extra yt-dlp args (optional)
# VIDEO_DL_PROXY=http://127.0.0.1:7890           # Proxy (dedicated var)
# COOKIES_FROM=firefox                           # YouTube cookies: browser name
# COOKIES_FILE=/path/to/cookies.txt              # Or: path to cookies.txt file
```

### 4.2 Directory Structure

```
$VIDEO_DL_ROOT/
├── archive.txt                # Download archive (--download-archive)
├── index.html                 # Browse page (generated by gen-index)
├── player.html                # Player page (generated by gen-index)
├── channel/
│   └── <ChannelName>/
│       └── <YYYYMMDD>-<Title>/
│           ├── <Title>.mp4
│           ├── <Title>.en.vtt
│           ├── <Title>.zh-Hans.vtt
│           ├── <Title>.info.json
│           └── <Title>.thumbnail.jpg
├── playlist/
│   └── <PlaylistName>/
│       └── ...
└── single/
    └── ...
```

**Design rationale:**

- `channel/` / `playlist/` / `single/` — natural grouping for media library scanners
- One subdirectory per video — avoids file clutter
- `YYYYMMDD` prefix — chronological ordering
- `archive.txt` — deduplication (yt-dlp native)
- `temp/` — prevents half-downloaded files from being picked up by media players

### 4.3 Download Capabilities

#### Video

- Single video, playlist (recursive), channel/user full archive
- Resume interrupted downloads (yt-dlp native)
- Skip already downloaded (via `archive.txt`)

#### Subtitles

- English priority, fallback to configured languages
- Embedded + external subtitles (`.vtt` / `.srt`)
- Auto-generated subtitles (`--write-auto-subs`)
- All subtitles kept as external files (media player friendly)

#### Format Selection (Default)

- **Video**: Best quality ≤1080p (avoids huge 4K files by default; overridable)
- **Audio**: Best audio track
- Override via `VIDEO_DL_EXTRA_ARGS` or per-command flags

### 4.4 Naming Convention

```
File:    <Title>.<ext>
         Spaces → underscores, strip special chars (\/:*?"<>|)

Dir:     <YYYYMMDD>-<Title>
         Title truncated to 80 chars to avoid path length issues
```

### 4.5 Classification Logic (dl.sh)

The wrapper script determines the destination directory by inspecting yt-dlp JSON metadata:

```python
# Pseudocode
metadata = yt-dlp --dump-json <url>
if playlist_title exists  →  playlist/<playlist_title>/
else if channel exists    →  channel/<channel>/
else if uploader exists   →  channel/<uploader>/
else                      →  single/
```

### 4.6 Available Commands

```bash
# Download
just videodl::dl <url>                      # Default (≤1080p)
just videodl::dl-best <url>                 # Best quality
just videodl::dl-audio <url>                # Audio only
just videodl::dl-sub-only <url>             # Subtitles only
just videodl::dl-with-format <f> <url>      # Custom format

# Info
just videodl::list <url>                    # List formats/subtitles
just videodl::info <url>                    # Show metadata
just videodl::archive                       # View download archive
just videodl::update                        # Update yt-dlp

# Browse & Play
just videodl::gen-index                     # Generate index.html + player.html
just videodl::serve                         # Start HTTP server (auto-builds first)
just videodl::browse                        # Open in Finder
just videodl::play <keyword>                # Search and play

# Build
just videodl::build                         # Build all deps (static-server)
```

### 4.7 Retry & Timeout Strategy

| Parameter               | Default          | Override Needed?                               |
| ----------------------- | ---------------- | ---------------------------------------------- |
| `--retries`             | 10               | [no] Good enough                               |
| `--fragment-retries`    | 10               | [no] Good enough                               |
| `--file-access-retries` | 3                | [no] Good enough                               |
| `--extractor-retries`   | 3                | [no] Good enough                               |
| `--socket-timeout`      | 20s              | [no] Good enough                               |
| `--retry-sleep`         | None (immediate) | [warn] Added `exp=1:20` for proxy environments |

Configured in `dl.sh` via `--retry-sleep exp=1:20` for exponential backoff. Can be overridden
through `VIDEO_DL_EXTRA_ARGS`.

### 4.8 Static HTML Index (gen-index)

**Scan phase** (TypeScript + Node.js `fs` module):

| Target                   | Extracted Data                               | Purpose             |
| ------------------------ | -------------------------------------------- | ------------------- |
| Directory tree           | `channel/`, `playlist/`, `single/` hierarchy | Navigation tree     |
| `*.mp4 / *.mkv / *.webm` | File path                                    | Player source       |
| `*.{lang}.vtt`           | Language code from filename                  | Subtitles `<track>` |
| `*.thumbnail.jpg`        | Thumbnail path                               | Card cover          |
| `*.info.json`            | Title, date, duration                        | Card metadata       |

**Generate phase** (TypeScript template strings, [no] template engine):

- **`index.html`** — Main page
  - Left: collapsible channel/playlist navigation tree
  - Right: video card grid (thumbnail + title + date + subtitle badge)
  - Search/filter (pure JS, instant client-side filtering)
  - Pure HTML/CSS/JS, [no] external frontend dependencies

- **`player.html`** — Player page
  - URL parameter `?file=<relative path>` specifies video
  - Native HTML5 `<video>` with dynamically created `<source>` and `<track>` elements
  - Subtitles centered via CSS `::cue` + JS cue alignment override (VTTCue API)
  - Auto-discovers available subtitle languages from the index page link (`&langs=` param)
  - "Back to list" link

### 4.9 Chrome Compatibility (static-server)

`file://` protocol is blocked by Chrome/Edge for media playback. Solution: a built-in Rust HTTP
server.

**Implementation:** [`tiny_http`](https://crates.io/crates/tiny_http) crate (~zero deps, [no] async
runtime), ~130 lines:

```
src/bin/static-server.rs
├── CLI arg or SERVE_ROOT env var → root directory
├── Listens on 0.0.0.0:8080 (configurable via PORT)
├── Serves files with correct MIME types
├── Auto-serves index.html for "/"
├── CORS headers for cross-origin access
└── Range request support for video seeking
```

**Why Rust + tiny_http vs alternatives:**

| Option                         | Problem                                           |
| ------------------------------ | ------------------------------------------------- |
| [no] `python3 -m http.server`  | Avoids Python stack                               |
| [no] `npx serve`               | Downloads HTTP package on every start             |
| [no] `cargo install miniserve` | Requires global install                           |
| [yes] **Built-in Rust binary** | Rust toolchain already present, Cargo.lock pinned |

### 4.10 Error Handling

| Scenario                 | Behavior                                                 |
| ------------------------ | -------------------------------------------------------- |
| Network failure          | yt-dlp auto-retry (10 attempts, configurable)            |
| Already downloaded       | Skipped via `archive.txt`                                |
| Subtitle unavailable     | Skip language, log warning, continue                     |
| Playlist partial failure | Continue remaining items, report errors at end           |
| Disk full                | Exit with error; `temp/` residue can be cleaned manually |

## 5. Installation & Setup

```bash
# 1. Install CLI tools
brew install yt-dlp ffmpeg node       # macOS

# 2. Configure
cp config/.env.example config/.env
# Edit VIDEO_DL_ROOT

# 3. Init directories + cookies
just videodl::init
just videodl::cookies   # export browser cookies (one-time)

# 4. Done. Start using:
just videodl::dl "https://youtube.com/watch?v=..."
just videodl::gen-index
just videodl::serve   # → http://localhost:8080
```
